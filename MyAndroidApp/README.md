# 我的Android应用

这是一个使用现代Android开发技术构建的示例应用程序。

## 功能特性

- ✨ 使用Kotlin编程语言
- 🏗️ MVVM架构模式
- 🎨 Material Design 3设计风格
- 📱 ViewBinding支持
- 🔄 LiveData数据观察
- 🎯 ViewModel生命周期管理

## 技术栈

- **语言**: Kotlin
- **最小SDK版本**: 24 (Android 7.0)
- **目标SDK版本**: 34 (Android 14)
- **架构组件**: ViewModel, LiveData, ViewBinding
- **UI组件**: Material Design Components
- **构建工具**: Gradle 8.4

## 开始使用

### 前置要求

- Android Studio Arctic Fox或更高版本
- JDK 8或更高版本
- Android SDK (API Level 34)

### 运行应用

1. 在Android Studio中打开项目
2. 连接Android设备或启动模拟器
3. 点击"Run"按钮

### 构建项目

```bash
./gradlew build
```

## 应用功能

- 欢迎消息显示
- 计数器功能
- 重置按钮
- Material Design界面

## 架构说明

采用MVVM架构模式，分离UI逻辑和业务逻辑。
